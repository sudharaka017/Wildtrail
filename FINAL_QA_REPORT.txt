KNOWN UNIVERSITY-DEMO LIMITATIONS (NOT DEMO-BLOCKING)
- Localhost uses local_demo payment. Real PayHere callbacks require public HTTPS.
- Refund completion is recorded manually by admin; there is no gateway refund API/financial ledger.
- Reservation expiry/completed-state housekeeping runs during web requests rather than a production cron/scheduler.
- No email/password-reset service; notifications are in-app.
- One vehicle profile is managed per driver account in this build.
- Remote park/species imagery and Leaflet/OpenStreetMap map assets need internet access; core booking pages still work without those visual assets.
- Park-zone circles are demo/operational zones, not official DWC boundary polygons.
- The execution environment used for this final audit did not provide a running MySQL/XAMPP browser stack, so database-backed browser clicks were reviewed from the code/schema rather than claimed as live XAMPP execution.
